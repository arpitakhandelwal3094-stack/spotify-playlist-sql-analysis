# Spotify Playlist Track Analysis

## Problem Statement
Analyze Spotify playlist data to understand relationships between users, playlists, and tracks.

## Dataset
- Multiple relational tables:
  - Users: 10 records  
  - Playlists: 10 records  
  - Tracks: 20 records  
  - PlaylistTracks: 37 records  
- Structured dataset used for SQL-based relational analysis

## Tools & Technologies
SQL

## Analysis Performed
- Joined multiple tables to extract meaningful insights  
- Analyzed relationships between users, playlists, and tracks  
- Identified track usage and playlist patterns  

## Key Insights
- Tracks are distributed across multiple playlists  
- User activity is linked to playlist creation  
- Relational joins help uncover hidden patterns  

## Conclusion
SQL queries effectively analyze structured relational data and reveal meaningful insights from multiple tables.
